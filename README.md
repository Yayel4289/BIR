## *Deep Learning* : Adaptation de domaine
Travail de recherche effectué dans le cadre de ma **Bourse d'Initiation à la Recherche** (BIR) au sein de l'[UMONS](https://web.umons.ac.be/fr/) et ayant pour sujet l'adaptation de domaine en *Deep Learning*. Ce travail est consigné dans le rapport présent sur ce répertoire : [Rapport Bir - Adaptation de domaine](https://github.com/Yayel4289/BIR/blob/main/Rapport%20BIR%20-%20Adaptation%20de%20domaine.pdf).

L'implémentation est disponible via une [RELEASE](https://github.com/Yayel4289/BIR/releases) ou un clonage :
```bash
git clone https://github.com/Yayel4289/BIR
```
Le fichier `run_exp.py` permet de visualiser et exécuter les différentes expériences réalisées, veuillez consulter sa documentation (disponible avec le flag `-h | --help`) pour ce faire.
